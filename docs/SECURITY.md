# أساس أمان Cible

توثق هذه الصفحة ضوابط التطبيق الحالية ومتطلبات إعداد بيئة التشغيل. لا تُعد شهادة أمنية أو بديلًا عن فحص الخادم والشبكة.

## ضوابط التطبيق

- تتطلب لوحة Filament تسجيل الدخول، وتحد محاولة الدخول إلى خمس محاولات خلال دقيقة عبر مكوّن الدخول المضمن.
- يفرض Laravel حماية CSRF على طلبات الويب. تُجدد الجلسة بعد نجاح الدخول، وتُدار صلاحيات كل سجل في الخدمات والـ backend مع عزل بيانات الإيجار وإعادة البيع.
- تُخزن كلمات المرور باستخدام hash، والحد الأدنى عند إنشاء حساب أو تغيير كلمة المرور 12 حرفًا.
- جلسات التطبيق مشفرة افتراضيًا (`SESSION_ENCRYPT=true`). تكون علامة `Secure` على cookie الجلسة مفعلة تلقائيًا عندما تكون `APP_ENV=production`، ويمكن ضبطها صراحةً عبر `SESSION_SECURE_COOKIE`.
- تضيف لوحة الإدارة `nosniff` و`SAMEORIGIN` وسياسة إحالة محددة وسياسة أذونات تمنع الكاميرا والميكروفون والموقع. تقيّد CSP مصدر `base-uri` إلى النطاق نفسه، وتحظر الإضافات ومحتوى الإطارات خارج النطاق. يرسل HSTS في الإنتاج (`max-age=31536000`)، لذا يجب أن يكون الإنتاج متاحًا عبر HTTPS.
- سجل التدقيق غير قابل للتعديل أو الحذف من التطبيق، ولا تحذف أحداثه أو بيانات CRM التاريخية تلقائيًا (`D-071`، `D-072`).
- يطلب النظام من مدير الشركة فقط إعداد تطبيق مصادقة TOTP عند أول دخول، ثم إدخال رمز التطبيق عند تسجيل الدخول. يوفر Filament رموز استرداد لمرة واحدة؛ خزّنها في مكان آمن ومنفصل عن كلمة المرور. لا تُفرض MFA على الموظفين (`D-075`).

## متطلبات النشر

- استخدم `APP_ENV=production` و`APP_DEBUG=false` و`APP_KEY` قويًا وفريدًا ومحفوظًا خارج المستودع. لا تعِد استخدام مفتاح التطوير.
- قدّم الموقع عبر HTTPS، واضبط `SESSION_ENCRYPT=true`. لا تعطل `SESSION_SECURE_COOKIE` في الإنتاج.
- اجعل مجلد `public` فقط جذر الويب، وامنع الوصول الشبكي العام إلى MySQL وphpMyAdmin وملفات `.env` والنسخ المحلية.
- استخدم مستخدم MySQL مخصصًا بصلاحيات التطبيق الضرورية فقط، ومفاتيح R2 بصلاحية الوصول إلى bucket النسخ المحدد، واحفظها في مدير أسرار الخادم.
- شغّل Laravel scheduler، وراقب سجل النسخ والتنبيهات، واختبر الاستعادة دوريًا في قاعدة منفصلة؛ احتفاظ نسخ R2 محدد بـ30 يومًا (`D-068`).
- عند وضع التطبيق خلف reverse proxy أو Cloudflare Tunnel، لا تثق بجميع ترويسات الوكيل دون تحديد الوكلاء الموثوقين. اضبط ذلك وفق شبكة الخادم الفعلية حتى لا يمكن تزوير عنوان العميل أو حالة HTTPS.

## ضوابط لم تُحسم أو لم تُثبت تشغيليًا

- يلزم إكمال إعداد تطبيق المصادقة وحفظ رموز الاسترداد لحساب مدير الشركة بعد تطبيق migration؛ لا يمكن للمدير دخول اللوحة قبل إكمال الإعداد.
- تقييد عنوان IP للوحة الإدارة، وتدوير المفاتيح، والتشفير على مستوى قرص قاعدة البيانات، وخطة الاستجابة للحوادث تحتاج إعدادًا تشغيليًا مستقلًا؛ تظل ضوابط الأمن التقنية الإضافية ضمن `Q-013`.
- تغييرات إعدادات الإنتاج، صلاحيات النظام، firewall، Cloudflare Access، ونسخ الإنتاج لم تُثبت بهذه المراجعة المحلية.
