# Stage 6 — Comprehension Test (Round 2)

## What this proposes

The design records the main source a client identifies for how they learned about Cible on each Rental or Resale request. Stable source types control which fields appear and how selections are validated: personal referrals require a name or explicit unknown state, while «أخرى» requires a description. Phone calls, visits, and WhatsApp become inactive historical choices; unknown sources remain unset, and the linked property broker is not treated as the referrer.

## How the existing system works, per this document

The current source list mixes ways clients learn about Cible with ways they contact it. The form provides an extra description only for «أخرى», while it has no separate referrer field or stable type for manager-added choices. Rental and Resale retain separate source catalogs.
